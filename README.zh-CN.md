# 剪辑室 Cutting Room

[English](README.md) | **中文**

面向编码 Agent 的剪辑技能库，遵循 Agent Skills 开放标准（SKILL.md）。提供素材规格盘点、DaVinci Resolve 时间线自动化剪辑、量化审片与 AIGC 视频片段质检能力。

`install.sh` 装到 Codex 的用户级目录。其他工具读各自的 skills 目录（Cursor 与 Antigravity 读仓库内的 `.agents/skills`，Claude Code 读 `~/.claude/skills`），把仓库克隆过去即可。

---

## 安装

```bash
curl -fsSL https://raw.githubusercontent.com/Maoxintao98/cutting-room/main/install.sh | bash
```

脚本会检查 `ffprobe` 是否就绪、校验 SKILL.md、配置脚本执行权限，并安装到 `~/.agents/skills/cutting-room`。

也可以手动克隆：

```bash
# 全局生效
git clone https://github.com/Maoxintao98/cutting-room ~/.agents/skills/cutting-room

# 单仓库生效
git clone https://github.com/Maoxintao98/cutting-room <项目路径>/.agents/skills/cutting-room
```

使用时输入 `$cutting-room`，或直接下达任务（如“盘点素材”、“在达芬奇里起粗剪时间线”、“审一下成片并列出时间码问题”）。

## 四种用法

| 用法 | 触发条件 | 输出交付 | 参考文档 |
| :--- | :--- | :--- | :--- |
| **定方案** | 拿到素材，确认剪辑方向 | 明确片种与唯一主目标，确定技法侧重与剪接规则 | [craft.md](references/craft.md) |
| **执行剪辑** | 方案已定，需要搭建时间线 | 在 DaVinci Resolve 中建工程、铺片段、做字幕、调音频 | [resolve.md](references/resolve.md) |
| **审片** | 针对成品或粗剪做质量验收 | 六维评分、时间码证据、按改动性价比排序的修改方案 | [review.md](references/review.md) |
| **AIGC 选片** | 大批量生成片段筛选 | 瑕疵三级分类，按 KEEP / 可修 / NG 决策树分流 | [clip-qc.md](references/clip-qc.md) |

## 审片准则

1. **不软化结论**：禁用「整体不错，但是……」「瑕不掩瑜」等模糊表述。结论只下：能用、需修、重做。
2. **不凑数**：没问题写无问题，不为显专业捏造问题，不为格式对称硬凑优点。
3. **每条判断必须有时间码**：必须精确到秒、帧或镜头号。禁用「高级、有质感、节奏好」等无法量化的词汇。
4. **区分事实、共识与偏好**：主观偏好必须标明【偏好】，不能作为合格评判依据。
5. **优缺点标准一致**：优点必须如缺点般具体，且需指出全片最好的一个镜头及技术成因。肯定时不再用转折词削弱。
6. **只评价作品**：评价仅针对画面、声音与结构，不针对人。
7. **否定必须给解决方案**：指出问题的同时给出具体的修改路径或技术替代。
8. **明确信息缺口**：缺少 Brief、投放平台或技术指标时直接标明，不作凭空假设。

## 审片报告示例

```text
片名/版本：demo-v1        片种：品牌氛围片    时长：25s    画幅：16:9
【信息缺口】未指定投放平台，无法评估竖屏安全区
─────────────────────────────────────────────────────────────
一、成立项
  1. 最佳镜头：00:12 水滴落下镜头前推，方向与前一镜旋转同向（动势匹配剪）。
  2. 00:06 处 0.8s 留白由动作触发，有效将注意力拉回主体。
  3. 全片色温与光比统一。

二、六维评分（0 无异常 / 1 轻微 / 2 明显 / 3 致命）
  1 叙事推进            1/3  [00:03] 与前后镜头无因果关系，倒序播放仍成立
  2 视听协同与声音设计  2/3  [00:18] 音乐全程电平一致，高潮前无能量推进；缺关键动作音
  3 视觉构成与图文      1/3  [00:09] 字幕压在人物面部
  4 镜头间连续性        2/3  [00:07] 全景硬切特写，无过渡支点
  5 信息与品牌一致性    1/3  未建立产品核心卖点
  6 时间节奏与速度      2/3  [00:15] 变速方向与下一镜动势相反

三、问题清单（按改动性价比：收益 / 成本 排序）
  1.【高收益·低成本】00:18 音乐高潮前抬升 4dB 并补入动作音 → 视听推进更清晰
  2.【高收益·低成本】00:03 删掉该空镜头 → 节奏加快，信息更紧凑
  3.【高收益·高成本】00:05-00:09 主体结构变形 → 需修改提示词重新生成

四、结论
  [ ] 能用    [X] 需修（按上述清单处理）    [ ] 重做
  总评：各镜头单看合格，组合缺乏连贯逻辑。
```

## 理论依据与标准

内化 24 部剪辑理论专著、19 篇生成视频质量评估论文及 27 篇工业技术规范：

- **剪接点仲裁**：情感 51% > 故事 23% > 节奏 10% > 视线 7% > 二维平面 5% > 三维空间 4%。冲突时从上往下保，从下往上牺牲。
- **AIGC 瑕疵分类**：
  - 一级（表层）：偏色、频闪、局部噪点。
  - 二级（结构）：非预期形变、多肢、遮挡穿模。
  - 三级（时序-语义）：不可逆物理违例、因果断裂、跨镜头一致性破坏。

## DaVinci Resolve 注意事项

- **时间线起始帧**：DaVinci Resolve 默认时间线起点通常为 `01:00:00:00`（第 86400 帧），时间码转换与帧计算需以此为原点。
- **工程安全**：批量操作或编辑前新建时间线或另存项目，不直接覆写用户原始工程。
- **交付检查**：导出前运行 `steps/00_inspect_timeline.py` 检查各视频轨连续性及未预期的空隙。
